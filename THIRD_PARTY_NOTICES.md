# External dependencies

Cataclysm & Nouveau is an independently authored addon and requires the original
L_Ender's Cataclysm, Ars Nouveau and Ars Conflux. It is not a port or redistribution
of Cataclysm. MIT covers this addon's own code only.

Cataclysm is by L_Ender. Its published source license is CC BY-NC-ND 4.0;
its assets are all rights reserved. Their licenses are unchanged by this addon.
Official license: https://www.curseforge.com/minecraft/mc-mods/lendercataclysm/license
Official source: https://github.com/lender544/new1.20.1

Our item-model JSON files contain paths to Cataclysm's installed item models.
Native entities use Cataclysm's own registered renderers, particles and sounds.
No Cataclysm textures, models, sounds, source bodies, classes or dependency JARs
are included in distributable artifacts. Dependencies must be obtained separately.
Local ignored `libs/` files are development inputs only.
