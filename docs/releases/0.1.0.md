# Cataclysm & Nouveau 0.1.0

First public release for Minecraft 1.21.1 / NeoForge.

- 102 Ars Tier 1 glyphs adapting selected Cataclysm boss, creature, and weapon abilities.
- Native projectile replacements, targeted effects, sustained beams, buffs, and action phantoms.
- Scribe's Table acquisition using Cataclysm materials and Source Gems.
- Trigger-based Ars Mana costs, configurable cooldowns, Ars damage growth, and percentage-damage safeguards.
- Surviving projectiles continue their Ars arrangement after each successful native hit; native invulnerability and damage cancellation still apply.
- English and Simplified Chinese localization.

Requires Ars Nouveau, Ars Conflux 0.1.24+ within 0.1.x, Cataclysm, and their dependencies. Install on client and server. Cataclysm remains separately installed; no upstream code or media is bundled.
