# 目标生命比例伤害封顶

dev.30，NeoForge 1.21.1；依据实际 Cataclysm 3.33 JAR。Core 固定 `9611f5087e3dd5adad6cd21517bb9563dd9a83dd`，未修改 Core 受版本控制文件。

## 规则

服务端配置 `[damage] cap_health_damage = true`。仅本附属的施法上下文生效，计算 `固定部分 + min(目标最大生命 × 原生比例, 固定部分)`，随后才接增强／削弱和 Ars 事件／属性加成。关闭恢复原生行为，包括原本已经存在的原生封顶。不是总伤害绝对上限，不改变百分比本身，也不改爆炸、原生 Boss 攻击、费用或冷却。

## 实际发布包审计

扫描所有已接入 NativeArsDamageMixin 的本体类，仅九种包含 getMaxHealth 引用，逐项核对伤害用途：

| 来源 | 原生状态 | 处理 |
| --- | --- | --- |
| 普通／灵魂焰魔火球 | 6／8 + 7%，未封顶 | 比例部分最多 6／8，包含剑刃阵子弹 |
| 深渊火球 | 10 + 20%，未封顶 | 比例部分最多 10 |
| 焰魔近战、冲撞、地面波 | 各段攻击倍率 × 攻击属性 + 比例，未封顶 | 按各段倍率后的固定伤害封顶；通过约束该伤害表达式的生命输入保留原生攻击体 |
| 斯库拉 Lightning_Storm_Entity | 实体 damage + hpDamage × 最大生命，未封顶 | 比例部分最多实体 damage；包含雷矛、电火花、连排落雷等产生的子落雷 |
| 斯库拉原生近战 | 已限制比例部分不超过固定部分 | 保留 |
| 巨兽震地 | 已限制比例部分不超过攻击属性 | 保留 |
| 末影守卫近战 | 已限制比例部分不超过该段固定部分 | 保留 |
| 死亡激光 | 已限制比例部分不超过 beam damage | 保留 |
| 先驱者冲撞 | 已限制比例部分不超过攻击属性 | 保留 |

未接入的 Flame_Strike_Entity 也有未封顶公式，后续新增该能力时须接同一规则；当前不新增或修改尚未接入的载荷。

火球爆炸半径 1／2，无遮挡、距离趋近零时原始伤害上限为 15／29。直接命中先发生，随后爆炸；原生受伤无敌时间通常只允许较高的第二次伤害补差，不能把两段直接相加。爆炸不属于最大生命比例伤害，因此本开关不限制它；它仍吃既有增强和 Ars 法强。
