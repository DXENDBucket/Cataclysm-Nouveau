# 焰魔动作锚点推广（dev.35）

迁移范围：普通跃砸、强化跃砸、地动三连和终极焰斩。剑舞共用本批提取的水平瞄准辅助，保留两段原生 Goal 和既有转向窗口。Core 固定 `a14acc36b10c933eb3447afb0f7ed540e7c3365b`（0.1.20），本体依然是 NeoForge 1.21.1 的灾变3.33。没有修改 Core、制作新魔符、改配方或调整费用／冷却／伤害。

## 实体与固定点

所有五种动作只接受施法者自身、Core 友军或真实方块位置。敌方实体、非生物实体与 MISS 不启动，费用由现有触发事务退回。damageOwner 的关系不能授权控制实体；伤害保护仍沿用原有保护施法者、执行者及友军的规则。

实体位置与碰撞框随实际执行者采样，运动只应用于该实体，实体动作占用为独占 ENTITY_ACTION。共享 CHANNELING 可以并存。玩家取镜头方向；生物优先取有效攻击目标，再尝试当前视线中的敌人，最后取自己的朝向。目标失效后可以重新瞄准，不将一次性选中的敌人视为整个动作的生命周期所有者。

固定点冻结精确坐标及触发方向，采用0.6×1.8调用框，executor=null，没有实体动作占用，不更改施法者速度、重力或镜头。空中的原生地面攻击仍受原生地形检查约束，不凭空创建地板。位置跃砸不模拟移动或真实腾空：原生准备阶段后，以固定调用帧的着地状态进入落地打击。普通为第19 tick取得跳跃准备，第20 tick转换；强化为第84 tick准备，第85 tick转换。所有挥击、火球、落地阶段的伤害与时序继续来自本体 Goal／aiStep。

原生 Goal 所需的 ArmorStand 输入对象始终未注册，只表达瞄准坐标。子火球的追踪目标独立解析为真实敌人，不把这个临时输入当成敌人或伤害所有者。调用帧也不出生、不存档、不进行 Boss 常规 AI。

## 转向与原生阶段

本批水平转向上限仍为20°/tick，出手方向同时用于原生伤害及视觉快照。原生 Goal 临时计算的 yaw 在攻击前被统一姿态覆盖；不改变执行者自己的镜头。

| 动作 | 可以转向的阶段 |
| --- | --- |
| 普通跃砸 | 空中准备／飞行；进入落地阶段后锁定 |
| 强化跃砸 | 准备tick<25、36<tick<55、tick>66；进入落地阶段后锁定 |
| 地动三连 | tick<31、45<tick<73、89<tick<117 |
| 终极焰斩 | tick<72；之后重斩及收尾锁定 |

实体跃砸仍第19／84 tick将原生跳跃冲量给执行者，并等待真正 onGround 后转换。强化的普通／灵魂空中阶段及两种落地阶段都保留。地动三连仍32／73／117 tick重击，终极焰斩仍保留准备火环及74 tick重斩／八道火场。

## 取消与子攻击

每次检查锚点生命、旁观状态、维度、友军授权、骑乘与所需加载范围。失去有效性按取消结束；长期未落地按过期结束。清理只作用于已启动的本会话：关闭幻影、释放本会话动作锁、恢复被修改的重力和衰减实际执行者的水平运动。

每个调用帧单独登记其原生子火球／火场。取消时清理这些子实体，不能按施法者或区域批量删除；同一玩家独立施放的火场仍保留。自然完成后已生成的子攻击继续按原生寿命执行，仍受根所有者及其各自会话的生命周期检查约束。准备失败不停止别人的 Goal、修改重力或解除已有动作占用。

## 幻影协议与验证边界

协议版本3将原来的两段剑舞ID保留为1／2，新增八个显式原生动画ID，统一由 `IgnisAnimations` 映射。客户端不运行代理tick／AI／攻击，按快照使用本体模型、贴图和渲染器；服务端发送开始、阶段切换、每4tick更新和关闭。未知动画或无效进度被拒绝，断更租约仍16tick，关闭淡出6tick，换世界清空。

新四种动作的显示独立受 `action_phantoms.ignis_actions=true` 控制；既有剑舞开关不变，透明度与比例共用。无论开关如何，伤害和动作不受影响。

针对性服务端套件使用 `-PgameTestNamespaces=cataclysm_nouveau_ignis`，包含原生时序、剑舞回归、四动作的选点／付费／固定点／授权取消、原生子攻击及阶段载荷往返。实际模型外观、第一人称遮挡和其他优化模组中的显示仍需客户端人工确认。

斯库拉、先驱者和末影守卫完整锚点迁移仍留后续批次；独立剑刃阵、五火球阵与烈焰打击的原有选点规则不因这次物理动作迁移而改变。
