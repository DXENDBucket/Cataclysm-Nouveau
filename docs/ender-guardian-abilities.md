# 末影守卫行动审计与魔符候选

2026-10-12；实际依赖Cataclysm1.21.1-3.33、附属dev.22。只整理行为，不实现新魔符，不修改Core或版本，不运行游戏。

## 依据与边界

- 发布JAR的Ender_Guardian_Entity：registerGoals/tick/aiStep及各原生攻击方法；九个内部goal；Ender_Guardian_Bullet_Entity与Void_Vortex_Entity；CMCommonConfig.EnderGuardian；AltarOfVoid_Block_Entity的生成入口；实体掉落表。
- 反编译审计结果只放系统临时目录cataclysm-guardian-audit-20261012，不将本体源码/素材复制入仓库。
- 当前虚空符文魔符归于末影傀儡，使用傀儡伤害配置。末影守卫虽然复用相同实体，配置基准为9，不能视为已覆盖其符文阵。
- Boss基础攻击16、最大生命333、护甲20，攻击/生命倍率可由本体配置修改。以下时序按20tick/秒，不是玩家魔符费用或冷却承诺。

## 炮弹和漩涡的关键细节

- Ender_Guardian_Bullet不是追踪潜影弹：先用setUp的目标布阵位置和延迟进行重定位，延迟结束才fired，随后按预定方向加速，发射期30tick。直接命中6伤害，成功后漂浮I100tick。命中方块保留爆炸粒子及声音，没有在此执行伤害爆炸；发射后碰撞移除，受击也可被摧毁。炮弹阵共九枚，准备延迟30tick。单发替换必须明确如何初始化fired/延迟，不能漏掉布阵阶段也不能无意保留永远不生效的未发射状态。
- Void_Vortex是狭长竖向控制区：以落点为中心，水平±3格、向上15格的包围盒，预热约16tick后对非友军持续向中心及向下拉；结束有强度2的不破坏方块爆炸。原生有漩涡渲染、上方下降粒子和开启音效。它并非持续每tick固定伤害的黑洞。
- 漩涡原生拉动与结束爆炸没有整体由isClientSide守卫，制作时须分别核对两端执行和对玩家/友军的运动归属，不以服务器实体能出现作为完成标准。
- 引力重拳的GravityPull中心位于执行者前方；武器Gauntlet_of_Guard也有持续牵引，但中心在持有者位置，参数与友军过滤不同。两者不可混为完全一样的原生能力。

## 半血和生成来源

当前发布版synched USED_MASS_DESTRUCTION默认true；虚空祭坛生成Boss时明确设false。因此祭坛生成的守卫有一次半血转阶段震爆，不能断言所有刷怪蛋/直接new生成的守卫一定播放这一动作。普通半血判定是当前生命不高于最大生命的一半，破盔标记设置后保留；践踏/上勾拳和远距离空降选择读取此标记。

Boss还有未破盔时箭矢免疫、对部分炮弹免疫、伤害/DPS限制、自然恢复等防护。这些不等于独立施法能力，当前仅记录。

## 候选优先级和获取边界

首批优先考察：单发守卫炮弹、虚空漩涡、原生践踏符文阵、引力重拳。后续可看完整上勾拳炮弹连段、闪现突袭、空降重砸、火箭拳；普通拳/左右横扫与其他系列较接近，不必机械拆成多个魔符。

本体掉落表保证一只守卫掉一个守卫者护手，唱片低概率额外掉落；没有像巨兽电池或先驱者合金块一样的大量直接素材。若注册多项能力，不能每个都消耗一只护手，否则违反用户1–3次击杀学齐原则。获取方案尚未决定，不把候选清单当作制作授权。
