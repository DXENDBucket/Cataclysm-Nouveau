## 上下文、生命周期与两端表现

- 沙暴以 Core `ExecutionAnchor` 选择自身、友军脚部或固定位置；非友军实体不可作为环绕中心，失败退款。只在 native `updateMotion` 的中心采样中提供调用帧，伤害归属仍为真实 damageOwner。友军／固定点共用原生 Boss 八格环绕分支；不复制轨道算法。
- 沙碑是对选中位置的攻击，允许敌方目标；原生子实体 caster 重绑真实伤害拥有者。
- 地裂是范围效果，友军／自身可随其位置朝向，固定点保留触发方向；敌方命中则在该点按来向展开。它不推动执行者，不占用身体动作，允许与其他范围或体术并行。
- 沙暴、沙碑、地震波和调用帧仅 opt-in 接入伤害；通过 Core 关系排除友军，包括外部注册关系。普通灾变 Boss／原生弹体保留原有规则。
- 地震波原生普通触碰保留多次伤害，但每个实体最多一次 Ars 续接，且必须伤害成功；无敌帧／伤害取消不能产生额外续接。环绕等重复载荷每次有效接触独立扣费，未着地／友军目标拒绝，不足蓝在攻击之前结束。
- 特殊地震波保留完整原生视觉 tick，抑制原生位移和自动免费伤害，生命周期由 Ars 载体控制；不会在60tick偷偷结束环绕。没有第二套原生＋Ars运动叠加。
- 会话拥有其全部子实体：施法者／执行者离开或死亡、权限撤销、配置禁用、自然结束和未加载区域均停止清理，不主动加载区块。沙暴／沙碑／地震波不保存。地裂的可视碎块也随根会话取消。
- 脱离世界的 Boss 帧不运行 AI／基类 aiStep，不出生、不保存、不触发 Boss 音乐。地裂 `StompParticle` 原生客户端分支单独通过服务器发送相同粒子与速度；原生 `playLocalSound` 改为服务端位置广播，仅对该调用帧生效。
- 沙暴／沙碑使用原生实体注册和渲染，保留 native 实体事件与复杂出生数据。沙暴时间修饰同时同步原生出生动画阈值，避免延长后一直停在出生阶段。
- 图标仅引用原生 generated 物品模型，无需 builtin/entity 特殊委托。本体素材、模型或源码均未复制。

## 获取预算

四项均为 Ars 原生抄写台配方，各需要魔源宝石1、27经验。沙暴用瓶中沙暴1；沙碑和地震波各用远古金属锭1；地裂用遗魂头骨1。

实际本体战利品表必掉瓶中沙暴1、遗魂头骨1、远古金属块1；后者原生工作台拆9锭。所以一次保底击杀覆盖本批，余7锭，为后续扩展留有空间。不添加额外掉落或拆分材料。
