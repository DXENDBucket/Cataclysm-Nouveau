# dev.13：斯库拉第二批、熔岩行走着地与图标

- MC 1.21.1 NeoForge；Cataclysm 3.33；附属 0.1.0-dev.13。
- 固定 Core 0.1.16：`b24f18d72e64a902ff6c966040b0b83ea3cc6226`。Core 受版本控制文件不改；测试实例继续使用兼容的 0.1.17。
- 工作树：`parallel-workspaces/cataclysm-monstrosity-full/Cataclysm-Nouveau`；功能提交以本文件所在提交为准。

## 行为

新增电火花替换、连排落雷效果、雷暴云效果，复用现有 Boss 系列展示键。电火花保留原生抛物线、电弧、落雷与电场，原生没有实体直击伤害。普通轨迹对同一实体只续接一次；重复 Ars 形态每次付费。原生子效果不另外付费。

连排落雷、雷暴云直接从 detached Scylla 的 goalSelector 获取发布版本已经注册的 native goal。前者保留第 26／54 tick 两波九道及移动预判；后者默认形成 40 tick、降雨 31 tick，每 tick 一组原生水矛和雷矛。非实体选择用不出生的 ArmorStand 标记确定位置/朝向。云的水矛直击读取本体 SpearDamage，雷矛读取本体 SnakeDamage（当前默认分别 14／16），强化对两者均生效。雨云、降雨前的闪电爆发和声音由服务器显式发送原生资源，不能依赖未出生的 Boss 客户端 aiStep。

默认 Mana / 冷却：电火花 120 / 3 秒、连排落雷 320 / 10 秒、雷暴云 900 / 20 秒。时效修饰修改雷云降雨段，±50% 基准、最多 120 tick。形成延迟单独可配置，原生计时窗口映射为 115–145，不复制投矛实现。施法者消失或离开原维度、目标死亡/换维度/离开 48 格、必要区块卸载或魔符禁用均结束会话。子实体跟随真实施法者、Core 友军和瞬态清理规则。

雷暴云用风暴精华，其余两项用泪宝石；累计十二项相关魔符需要精华 6、泪宝石 10，含锚戟间接成本。两次击杀保底足够，另保留锚戟三次保底足够。

熔岩行走图标补齐原版 HUD +3/+3、背包 y+7 内边距。近熔岩表面视为着地并停止轻微浮升，保留真实跳跃；深处浮起、潜行下潜和临时伤害保护保留。着地检查覆盖已经浮出液体但仍贴近表面的情况，不强行把高处/跳跃中的实体判为着地。Boss 自带 canStandOnFluid/floatStrider；本附属是临时状态适配，不声称完整复制巨兽实体规则。

## 验证

- 编译、本地化（26 魔符）通过。
- 33 项服务端 GameTest 全部通过，新增三项覆盖电火花原生落地/重复扣费/空蓝、雷云完整 31 对投射/归属/单次扣费/离开清理、两排共 18 道落雷与自然结束。

- 最后补充降雨前原生闪电闪光，随后再次 `:build` 打包通过；未为客户端粒子重新跑战斗测试。

- 客户端图标位置、云粒子、两种矛的动画与电火花外观未人工确认；可选附属各形态仍按 Core 适配，未声明全矩阵人工测试。
