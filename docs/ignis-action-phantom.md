# 焰魔剑舞幻影样例（dev.32）

仅焰魔剑舞，客户端视觉能力。原生Ignis_Renderer、Ignis_Model及原生纹理层均运行时调用／引用，没有复制模型、贴图或实现。Core仍固定0.1.19，未修改其受版本控制文件。

## 角色和时间

- 服务端仍使用既有SpellIgnis调用帧执行动作与伤害；只有剑舞发送视觉快照，不把真实Boss注册进世界。
- 每个动作使用Core执行会话UUID作为视觉标识，实际执行者同时携带entity id与UUID防止id复用；维度标识阻止旧世界消息影响新世界。
- 快照只含实际位置、攻击朝向、根施法者阶段、COMBO1／COMBO2与该阶段年龄。起始／换段即时发送，动作中每4tick更新，客户端最多向前推4tick，不由客户端自主切段。
- 默认向执行者的追踪者和执行者本人发送。取消／结束时，执行者可能已从追踪表移除，因此用调用帧最后的位置和原世界通知附近96格观察者，并单独通知玩家执行者本人。换世界的本地玩家会清空旧缓存。
- 客户端模型跟随执行者插值位置，朝向来自真实攻击调用帧；不跟随玩家随意转动的镜头。无人可见或执行者id／UUID不匹配时不渲染。

## 渲染

- ClientLevel内创建未注册的Ignis_Entity，只作原生renderer所需的视图对象。绝不调用其tick、aiStep、Goal或攻击；没有世界实体、碰撞、仇恨、掉落、Boss血条、音乐和物理。
- 直接调用完整原生renderer，不只渲染裸模型；盾牌及护甲裂纹层共用alpha包装。纹理位置通过客户端只读Mixin访问原生RenderType／CompositeState／TextureState，不改全局材质或其他实体。
- 有纹理的层映射到vanilla entityTranslucentEmissive，保留纹理、顶点颜色／alpha与覆盖信息；材质COLOR_WRITE不写深度，正常深度测试阻止透墙。只flush本次使用的材质，不重置全局shader／颜色。
- 原生普通／灵魂纹理仍按阶段选择；未破盾采用原生举盾战斗基础姿态，破盾采用持剑姿态。动画进度通过原生模型的动画器绘制；没有另写一套剑舞动画。
- 出现约4tick淡入，显式结束6tick淡出；未收到更新16tick后租约到期，后6tick淡出。切世界、执行者死亡／消失、禁用配置时清理／隐藏。
- 客户端 `[action_phantoms]`：`ignis_sword_dance=true`，普通不透明度0.28，自己的第一人称0.14，尺度1.0；纯视觉参数，不改变原生伤害范围或资源。模型完整度和攻击图像与实际区域的视觉匹配仍需人工观察，默认不缩放避免缩小原生武器伸展。
