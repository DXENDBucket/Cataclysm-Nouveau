# dev.50：利维坦首批四项

2026-10-19。实现依据与未选候选见[原生审计](leviathan-abilities.md)。本批只接深渊灵珠、水雷、冲击波和轰炸，不加入裂隙、成对传送门、抓取、阵列或利维坦体术。

基线：附属 `c5985d0990fd4ccd981572e2c445a6c547ecc680`；固定 Core `ed44ebb86bd087f3546a1bc6a315d2692f70262c` / 0.1.28。Core 受版本控制文件不改；仍使用现有最低 Core 0.1.21 的 API。MC 1.21.1 NeoForge；本体 Cataclysm 3.33，SHA-256 `371956d0c2e3b56729ee93b955e936875d210e372fe734cdb74326d89ef79875`。

## 最终行为与默认值

| 魔符 | 类别 | 默认额外 Mana | 主动冷却 | 获取 |
| --- | --- | ---: | ---: | --- |
| 深渊灵珠 | 弹射物替换增强 | 60 / 发或重复接触 | 无 | 利爪碎片 ×1 |
| 深渊水雷 | 位置效果 | 80 / 枚 | 1 秒 | 利爪碎片 ×1 |
| 深渊冲击波 | 持续光束效果 | 80 / 每输出秒 | 10 秒 | 潮汐利爪 ×1 |
| 深渊轰炸 | 位置效果 | 300 / 次 | 8 秒 | 利爪碎片 ×1 |

各配方另需魔源宝石 ×1、27 经验。利爪拆九碎片，碎片暂引用本体虚空碎片图标；全套耗一把整爪与三碎片，即两次固定掉落足够，还有六碎片余量，未消耗深渊之卵。魔符、物品和法术书内沿用同一系列排序。双语名称、增强提示与 Core 边框继续走现有展示路径；利爪和卵图标通过本体物品身份委托真实渲染器，发行包不含本体素材。

- 灵珠使用真实 `Abyss_Orb_Entity`，直接伤害读本体配置，默认 4；40 tick 后开始原生追踪。没有可见目标仍可发射，按本体无目标规则继续。普通发射保留原生惯性、追踪、约 25 秒到期爆炸；年轻灵珠撞墙没有攻击，也不续接编排。Ars 特殊形态负责轨迹与碰撞，原生 tick 只保留视觉，避免双重移动和自行到期爆炸。重复接触逐次收费，实体按成功伤害续接，空蓝先停止攻击。
- 水雷可悬浮，生成点必须已加载且没有实体体积与方块碰撞；基础存续 800 tick。保留原生预热、事件 4、粒子、接触引爆、10 秒禁疗和自然消失。触发者检查与爆炸范围都统一保护友军，同一 tick 多个接触者只引爆一次。
- 冲击波按 Core 有益执行锚点：自身/友军从眼部沿实时视线发射，方块触发保留固定位置及传入方向。敌方实体选中失败，不回退施法者。基础预热 20 tick、输出 duration 80 tick、随后原生淡出。只在输出段每秒预付，不足则在伤害前移除，淡出没有额外伤害。可以与其他非体术效果并行，不占用身体动作声明。
- 轰炸在落点附近最多四格内找地面，不强行补不存在的地面。原生门户在第 22 tick 创建竖直向上的真实子光束；基础子光束 duration 160 tick，门户自身 260 tick。子实体继承上下文、增强、真实伤害拥有者与取消清理，不再次收费，也不另执行 Ars 后续编排。
- 延长/缩短时效每份按基准 ±50%，沿用现有时长界限；水雷改存续，冲击波改输出时长及实际输出秒费用，轰炸改子光束时长，并给门户保留完整收尾余量。伤害增强/削弱沿用有上下限的 20% 步长；Ars 装备/事件桥接随后一次生效。

## 双端与生命周期边界

两种光束均保留深渊灼烧：成功伤害叠加 8 秒，最多 IV，低生命受害者仍可能被灼烧传送。默认基础伤害 10，最大生命附加项按本体实际 `hpDamage × 0.01` 并保留其封顶；不把配置 0.1 误读成 10%。药水后续 tick 不另加本批的 Ars 伤害桥接。

随身光束使用一个服务器会话驱动 native tick，正常世界 tick 不重复执行。服务器 yaw/pitch 与客户端渲染角读取同一同步值，不依赖伤害拥有者当前朝向；第一人称清晰视野依据实际发射者 ID，而非远处付款者。固定位置及友军光束不丢失应显示的起点。光束只在已加载区块内 raycast，在边缘截断，不为远端未加载区块取消近处有效攻击，也不主动加载地形。

水雷/门户额外同步存续标记和客户端初始时长，保留事件 4，并让晚进入追踪范围的接收端也能启动原生展开/粒子。所有受管理实体不存盘。根死亡/离开、权限或配置取消、自然结束和生成失败沿用 Core 会话清理；门户与子光束共同结束。客户端不查询服务端施法根决定删除自身。

原生爆炸伤害/击退与射线伤害都保护 Core 友军，保留真实根归属。光束只关闭联动实例的拆方块分支，保留命中末端光效；正常本体 Boss 不改。特殊轨迹只由 Ars 驱动，原生模型/粒子继续执行，初始加速在转换处叠加，普通追踪速度上限也随之调整。
