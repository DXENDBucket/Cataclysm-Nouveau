# 咒翼灵骸戟阵、戟斩与灵魂爆发 dev.47

2026-10-13，按用户授权制作下一批四项；用户进一步要求数值尽量与Boss一致。战斗数值调用实际Cataclysm3.33原生实现，未添加伤害倍率，也未改本体Boss。固定Core`08c307f3238b9b9aa7fd628b9771cd287160448d`（0.1.24），受版本控制文件保持只读，未新增Core API／其他附属依赖。

每份强化仍额外10Mana，形态和其他Ars魔符费用另算。整组能力只支付一次，子戟不另收费或重复执行后续编排；后续Ars效果在启动后立即继续。原有单体幻影戟30Mana／零冷却、虚空符文20Mana／零冷却保持dev.46配置。所有四种新魔符Tier1，按MALEDICTUS系列排序，各用咒魂锭×1＋魔源宝石×1、27经验。系列总计7种需7锭，最多3次保底击杀覆盖。

戟斩／爆发的250／150tick冷却参考本体native Goal.stop的冷却数值。Conflux按主动释放开始计时；原生Boss AI在动作结束后设置冷却，两种起点并非完全相同。两种独立阵列在Boss中属于落地动作的一部分，并无独立冷却，因此其Mana／主动冷却为本附属配置。原生73tick戟斩、66tick爆发动作时长与第15／44、34tick打击时序保留。

## 原生攻击与共享状态

`SpellMaledictus`不加入世界，不tick Boss AI；原生私有布阵由Mixin Invoker调用，完整戟斩和爆发使用本体Goal.start/tick/stop与aiStep。调用帧读取逻辑施法者的同一个怒气效果，真实付款者、执行者与damageOwner保持独立。未绑定的原生Boss与弹体不变。

每戟仍是本体Phantom_Halberd_Entity，伤害基准11×(1＋0.10×怒气)，普通0／3／5层为11／14.3／16.5；原生动画、事件4、伤害窗口、护甲／盾牌穿透及受伤无敌时间保留。各戟继承一次Ars增强／削弱和Core伤害桥接，不再乘额外阵列倍率。

近战基准取本体13×attackMultiplier×(1＋0.20×怒气)，首斩乘1.2、第二斩乘1，保留原生已封顶的目标最大生命比例项。hurt成功才叠加1怒气，后续目标／第二斩可读取新层数；满五层成功命中仍刷新200tick衰减计时。失败／友军不叠层，箭、戟阵与子戟也不额外叠层，普通近战武器未添加怒气。

爆发在34tick打击时由原生setRageMeter(0)清空共享状态，再计算`19.5＋min(19.5,最大生命×.15)`（本体默认值、无Ars修饰）；20／50生命为22.5／27，高生命上限39。预备期间不清空，爆发命中不重新叠层。范围保持本体物理框inflate(7)，不是数学半径7球。

## 位置、友军与生命周期

`ExecutionAnchor`和`ActionGeometry`给戟斩提供同一个驱动，自身／友军每tick采样实际执行者朝向并使用既有20度转向限幅；固定位置保留输入方向。敌方实体不能执行增益身体动作，不退回施法者，不扣启动费。位置不声明payer身体占用。

灵魂爆发是触发位置的独立范围效果，实体命中按其触发时的位置确定中心；它可与身体动作同时运行，打断戟斩不会取消爆发。两种阵列也是独立位置效果。戟斩只声明真实执行者的action claim，允许按Core既有方式打断；异常结束只清理自己的子戟，保留独立单戟／其他会话。正常结束让已生成子戟按原生寿命继续。

阵列先调用原生几何收集未加入世界的候选，只有合适地面才生成；不扩展区块加载。环形后续阶段按0／1／3／4tick推进，阶段生命条件按施法者实时读取；无第一圈地面但后续圈有可用落点也能启动。完全无有效地面失败退款。根失效、权限／加载区域丢失、禁用及自然结束通过Core处理；实际子戟不保存。最大候选螺旋100、环30／48／68、扇形八段162，数量不是保证生成量或实际伤害次数。

## 表现

身体幻影协议扩展MALEDICTUS，使用原生radagon／mass_effect AnimationState、武器形态和同步怒气信息。原生模型／纹理／renderer运行时引用，未生成真实Boss。延续各系列共享透明度、第一人称0.10、可配置开关；新`action_phantoms.maledictus_actions`默认启用。

原生aiStep中的客户端专属预告不会自动从服务器出现，因此统一补原生PHANTOM_WING_FLAME、Roar、Ring、CURSED_FLAME发送；实体和位置共用路径。阶段、粒子类型、声音和原生戟的客户端事件保留。粒子采用有限服务端批量采样，预备火焰的分布与原生客户端逐粒子圆盘采样、收尾球壳采样略有区别，不能称逐像素还原。原生客户端动画和实际画面仍待人工验证。
