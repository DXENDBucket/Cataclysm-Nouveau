# dev.53：灵珠环阵与三连深渊冲击波

## 范围与基线

用户授权制作两项非体术能力，不加入庞大利维坦身体幻影、抓取或成对传送门。MC 1.21.1 NeoForge，Java 21，附属 `0.1.0-dev.53`。起点 `07a2a984c7415d9098d8c83a1f8d47c58b5e6f6e`；固定 Core `ed44ebb86bd087f3546a1bc6a315d2692f70262c`，受版本控制文件不修改。构建仍只使用最低 Core 0.1.21 已有 API。

工作树 `parallel-workspaces/cataclysm-leviathan-dev53-20261019/Cataclysm-Nouveau`，分支 `feature/leviathan-volleys-dev53`。依据实际 Cataclysm 1.21.1-3.33 发布 JAR，SHA-256 `371956d0c2e3b56729ee93b955e936875d210e372fe734cdb74326d89ef79875`。原生反编译文件仍只在仓库外；分发中只有适配代码和资源路径。

正常三连的每束输出 duration 为 28 tick，每束在第 21/41 tick 预付两次，整组 6 次、480 Mana；最后不足一秒的段落仍按一秒预付。时效增强／削弱修改每束 duration，费用随实际预付秒数变化；伤害增强费用按原有报价规则计入每次预付。预热与淡出不另收费，没有未付费尾段伤害。费用和冷却沿用现有配置入口。

十项配方实际累计：潮汐利爪 ×2、利爪碎片 ×8、魔源宝石 ×10。三次保底击杀获得三把利爪，其中一把拆九片即可覆盖，剩一片；未新增深渊之卵消耗。两个效果魔符归入利维坦系列，图标分别引用深渊之眼／潮汐利爪；后者保留原物品渲染器身份。

## 灵珠环阵

使用同一 `ExecutionAnchor.beneficial` 判定自身、友军与方块位置；实体从眼部发出，聚能一秒内会跟随实际执行者。选中敌方实体启动失败，不能回退施法者。判断 12／24 珠使用逻辑施法者在启动时的生命比例，恰好半血也选择 24 珠，不能读取满血友军或无世界调用帧的生命代替。

一秒聚能是本魔符的前摇，没有要求玩家等待完整 Boss 转阶段动画。真正布阵不复制方向表：12 珠调用本体 `LEVIATHAN_STUN` 的 52 tick 攻击片段，24 珠调用 `LEVIATHAN_PHASE2` 的 90 tick 片段；保留三层 3/6/3 与五层 3/6/6/6/3、原生发射功率和 40 tick 后追踪。

仅调用无世界 `SpellLeviathan` 的攻击片段，跳过继承的 Mob aiStep，不 tick 导航、寻路或 Boss AI。调用帧禁用 Boss 音乐，避免用不存在的 Boss ID 同步音乐。原生出生口将 owner 换成真实伤害拥有者，位置换成真实执行锚点；每个弹体继承同一 Core 上下文、增强和来源能力。保留原生粒子、电弧、声音、爆炸、禁疗和自然结束。准备的末影粒子及释放的原生 Roar 粒子类型从服务端发送到实际锚点，避免丢失原本仅在 Boss 客户端执行的效果或沿用巨型身体偏移。

环阵整体收费一次，原生子珠不单独收费，也不复制 Ars 后续编排。弹体使用已有原生运动模式，不同时运行 Ars 轨迹；现有原生友军命中筛选与范围伤害保护继续生效。施法根、执行友军死亡／离开或能力禁用后全部清理；弹体进入未加载边界前取消，不为布阵加载区块。

## 三连深渊冲击波

完整调用实际注册的 `LeviathanBlastFireAttackGoal`：第 64/109/154 tick 创建三束原生 `Abyss_Blast_Entity`，每束另外保留 20 tick 预热和原生展开／淡出。原生瞄准窗口为 `<80`、`119–124`、`164–169`；在 80/125/170 锁定。位置沿执行者眼部移动，锁定的方向不再跟着随后的转头改变；固定位置使用命中传入方向。

延长时效时不同短束可能重叠，每束保存自己的锁定方向，后一束重新瞄准不能带转上一束。Native Goal 的 lookControl 不能和共享锚点同时控制朝向；出生口适配后由同一方向采样驱动服务端射线和客户端渲染。

原生 Goal 用调用帧构造光束，所以除了 `beam.caster`，还必须把 `setCasterID` 改成真实伤害拥有者；只改 Java 引用会给客户端留下不存在的 Boss ID。真正发射者另由既有 `LeviathanBeam.executor` 同步，用于友军眼部与第一人称视野，不与付款者混淆。

三束复用已有 `LeviathanLaser` driver，未另做一套伤害、粒子或资源结算。按每束实际输出秒预付；任一秒支付失败，在伤害前结束该束，并取消母序列及所有现存／未发射子束。短暂回蓝不会复活已经取消的后续攻击。创造模式仍可零蓝输出。只关闭受管理射线的拆方块分支，保留末端光效、深渊灼烧、伤害缩放及地形边界截断；正常本体 Boss 不改。

原生聚能和释放声音使用实体绑定音效包，无世界调用帧的 ID 无法被客户端解析。适配只对 `SpellLeviathan` 把原来的声音调用转为实际锚点的位置声音，保留原生音效、分类、音量和音高；真实 Boss 仍使用原调用，不重复广播两份可听声音。

两项均不申请身体动作或替换执行者，允许与其他非体术施法并行。所有原生子珠／光束只承担本能力攻击，不自动成为额外 Ars 效果触发器。

## 验证

首次 `:runGameTestServer :verifyDistributions -PgameTestNamespaces=cataclysm_nouveau_leviathan_volleys --offline --console=plain`，8/8 通过：

- 12 珠分层、延迟追踪、原生伤害／禁疗、爆炸友军保护及单次收费。
- 逻辑施法者半血时的 24 珠、五层方向、移动友军眼部和根失效清理。
- 敌方执行者拒绝、空蓝拒绝、创造零蓝，两种能力可并行。
- 三束出生时序、分段预付及正常总费用、固定方向、原生伤害／灼烧和完整淡出。
- 延长时效下不同束的独立锁定朝向、友军真实位置、友军失效清理。
- 未付费第二秒取消剩余整组，后续回蓝不会再发射。
- 现有单束的持续收费、友军朝向和创造模式回归两项。

静态复核发现原生构造器的 caster ID 仍指向调用帧，补齐真实 ID 后固定／友军两种三连场景 2/2 通过，并检查两个不同身份的同步值。继续核对确认实体绑定音效需要改为位置包，增加声音检查后最终定向 3/3 通过，没有重复完整旧矩阵。日志为工作区 `dev53-tests.log`、`dev53-owner-tests.log`、`dev53-final-tests-r2.log`；81 种魔符双语校验、二进制及源码 `verifyDistributions` 一并通过。

增加声音检查时的一次 2/3 失败来自测试注册器：`sounds::add` 的反射参数被推成 Object，NeoForge EventBus 无法确定事件类。改为有明确 Consumer 类型的 lambda 后通过，没有为夹具问题修改业务条件。该次失败保存在 `dev53-final-tests.log`。

客户端画面尚未人工验证：特别是原生环阵电弧／追踪外观、三束锁定的视觉和第一人称裁剪。没有另外启动 NEG／Hex／其他附属的共存矩阵。服务端通过不等于这些画面已验收。
