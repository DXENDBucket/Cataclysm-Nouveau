# 身体行动幻影扩展（dev.37）

## 范围

既有焰魔幻影保留，新增十个已实现身体行动的原生模型幻影：

| 系列 | 能力 | 客户端开关 |
| --- | --- | --- |
| 斯库拉 | 雷电重击连段、旋转挥锚、钩锚跃落 | `action_phantoms.scylla_actions` |
| 先驱者 | 冲锋撞击 | `action_phantoms.harbinger_actions` |
| 末影守卫 | 引力重拳、守卫上勾连段、闪现突袭、空降重砸、火箭拳 | `action_phantoms.guardian_actions` |
| 下界合金巨兽 | 肩撞 | `action_phantoms.monstrosity_actions` |

各开关默认开启。全部复用本体注册的模型、贴图、渲染层与动画，纯运行时引用，没有复制本体美术或实现代码。

第一人称不透明度默认从 `0.14` 调低为 `0.10`，更透明、较少遮挡；其他视角仍为 `0.28`。比例仍为 `1.0`，仅影响外观。已有自定义客户端配置优先；协调者部署测试实例时只更新仍为旧默认值的第一人称项。

## 执行和生命周期

视觉包装器转发原驱动器的启动、tick、结束、施法占用、实体声明和入射方向；不改变资源消耗、原生打击时机、移动、伤害、选择规则或打断规则。同步实际执行者的实体 ID/UUID、维度、位置、攻击朝向、原生动画/内部状态、阶段进度及半血/冲锋标记；付款者不会取代执行者作为视觉锚点。

启动、阶段变化和进度重置立即发包，普通阶段每四 tick 一次。自然结束、替换、失效均在原生清理之前发送结束包；原生 goal 提前清空动画时，结束包保留最后一个有效姿态。客户端只构建未注册的渲染代理，不调用 Boss tick、AI 或攻击，也不加入世界。16 tick 的租期处理丢包，结束后 6 tick 淡出，换世界清空。

斯库拉和巨兽使用原生 AnimationState；每次渲染按同步进度重建动画时钟，避免服务器已有攻击但模型未开始动画。斯库拉跃落的飞行末帧维持至真实落地，巨兽肩撞跟随实际重复的原生冲锋阶段。守卫与先驱者继续使用 Lionfish Animation，空降阶段切换和先驱者重复冲锋按实际帧同步。原生半血外观保留。

此次扩展针对现有实体身体行动。固定位置行动仍使用已支持位置锚点的焰魔实现；不新增其他系列的落点执行方式，也不新增 Boss 能力。

固定 Conflux：`030880436d93ae104d6e14ba0240b6b1ba698513`（0.1.21），副本受版本控制文件只读。
实际灾变依赖：NeoForge 1.21.1 的 `L_Ender's Cataclysm 1.21.1-3.33.jar`。

集中验证 namespace 为 `cataclysm_nouveau_phantoms`。覆盖十个真实行动的启动、更新、费用不变、占用不变和跨系列打断结束包，全部姿态的服务端协议往返及原生阶段，以及焰魔、跨系列重力恢复、守卫实际落地和先驱者碰撞的针对性回归。发行包和源码包均执行 `verifyDistributions`。

首轮16项实际检查通过15项，雷电重击连段因状态ID误映射失败；核对本体Goal构造参数后，将错误的24更正为实际25。针对失败项、协议和原生动画已清空/执行者已移除的关闭包补验，3项全部通过，共覆盖17个不同检查。新测试namespace最初缺少模板，修正独立模板后才执行上述检查；不能把这两次测试启动失败记为通过。

客户端画面没有人工验证。原生渲染器调用和动画路径的核对不等同于画面验收。
