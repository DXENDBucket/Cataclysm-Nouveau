# 咒翼灵骸候选审计

最初于2026-10-12完成候选规划；dev.44已实现幽灵之箭、单体幻影戟与咒翼怒气，其他条目仍为候选。依据实际 Cataclysm1.21.1-3.33 JAR（SHA-256 `371956d0c2e3b56729ee93b955e936875d210e372fe734cdb74326d89ef79875`），临时反编译位于系统临时目录 `cataclysm-maledictus-audit-20261012`。不复制本体实现／素材，首轮规划使用Core0.1.19；当前dev.44实现固定Core0.1.24，详见本轮交接。

## 推荐首批

名称除本体实体译名外均为暂称；这里只记录候选，不构成制作授权。

| 候选 | 形式 | 原生依据 |
| --- | --- | --- |
| 幽灵之箭 | 弹射物替换增强 | Phantom_Arrow_Entity，原生条件追踪、透明度、青绿色电弧／诅咒火焰拖尾与命中纹章 |
| 幻影戟 | 地面位置效果 | Phantom_Halberd_Entity，延迟显现、四种同步动画、攻击窗口及消退粒子／声音 |
| 螺旋戟阵 | 位置效果 | Boss StrikeWindmillHalberd，强化落地第4tick两组6×10与4×10，共100个候选落点；须有合适地面才生成 |
| 环形戟阵 | 位置效果 | 强化落地39／40tick的14＋16环；半血42tick再18，四分之一43tick再20，共30／48／68个候选落点 |
| 扇形戟浪 | 定向位置效果 | 状态26的radagonskill，44–58tick每2tick一段，距离2／4／6／8／10／12／14／16逐段推进；完整动作另有15／44tick近战 |
| 灵魂爆发 | 蓄势的位置范围效果 | 状态7，10／15／20预备粒子、30／33／36咆哮，34tick范围7的灵魂伤害；原生该次伤害前清空怒气 |

幻影戟没有飞行逻辑，不能因名称像长矛便当成弹射物替换。可以从同一原生载荷提供单戟、螺旋、环形和扇形布局；其主要差异是位置与延迟，尽量共用基础适配。

## 除首批外

- 地面四箭齐射：状态2，Goal第29tick四支箭，6度间隔、速度1.8；箭伤害读取PhantomArrowDamage与怒气。
- 空中四箭齐射：状态3，8tick起跳／后移、20悬停、50发四箭（9度间隔、速度1.5）、60取消飞行，再经状态4／5落地。不是多箭原地发射的同一行为；可考虑为自身／友军完整动作，但无需为了凑数量立即加入。
- 强化飞行重砸：状态24→25，实际落地后4／37两次区域打击，第一轮100个螺旋戟落点，第二轮两至四圈幻影戟。原生飞行、落地和持续子戟都要完整保留；可作为以后的一种代表性动作。
- 常规近战、上挑、连冲、旋斩和抓取抛落本轮不优先。抓取还包含强制骑乘和玩家第一／第三人称切换数据包，不能只做一次伤害便称完整。
- 断魂战戟Soul_Render有蓄力冲锋与潜行螺旋戟。武器版螺旋7×5共35个候选落点、伤害来自SoulRender配置；Boss版数量与伤害不同，同类效果按既有原则优先Boss版。武器冲锋依赖玩家专用RenderRushAttachment，不能直接给任意友军调用releaseUsing便称通用。

## 数值与语义边界

- Boss攻击属性原始基准13；近战DMG会乘怒气系数 `1 + 0.20 × 怒气`，通常0–5层。箭读取独立PhantomArrowDamage并乘 `1 + 0.05 × 怒气`，戟读取独立PhantomHalberdDamage并乘 `1 + 0.10 × 怒气`，不能统一一套比例。
- 原生成功近战会增加怒气，约每200tick衰减一层；爆发先清零再计算伤害。后续制作需明确固定起始怒气与同一动作中积累，或者独立的受控怒气能力，不擅自给玩家永久复制Boss怒气系统。
- 已核对的Boss近战、范围、地面波最大生命比例部分均原生封顶于对应固定伤害。沿用本体已有封顶，不用新增开关关闭它；新载荷若出现未封顶公式再沿用本附属damage.cap_health_damage。
- AreaAttack的maledictio布尔值选择伤害类型，并不等于给目标施加某个同名状态；箭doPostHurtEffects为空。不能凭名称编造一个附加诅咒debuff。

## 适配时必须保留

- 幽灵箭继承AbstractArrow，原生速度大于1.25、年龄大于2且目标较远时才修正方向。普通发射保留原生条件，特殊Ars轨迹由形态驱动，视觉装饰不得叠加第二次运动。箭命中伤害直接读取baseDamage，并非默认箭的速度乘伤害。
- 原生玩家构造器将pickup设为ALLOWED，默认拾取物是普通箭；魔符弹体必须防止产生免费物品箭。tickDespawn的200是落地后的计数，不能误当全程10秒寿命。
- 幻影戟warmup到-10选择1–4动画、-13至-33为伤害窗口，原生无敌帧限制实际命中频率；70tick后移除。服务器实体事件4开启客户端计时／声音，state字段开启模型动画，客户端4tick命中纹章、55tick消退粒子都不能省去。
- Boss调用帧不真实出生，原生仅客户端的戟阵／爆发预备粒子需要显式服务器传输；不能只发伤害实体漏掉预告和收尾。
- 统一真实付款者、伤害拥有者与执行者；位置戟阵子攻击不另收费、不重复复制后续Ars编排。伤害、控制／运动与状态都排除友军。根失效、维度变更、区块缺失／禁用时通过Core清理，不修改本体普通攻击。

## 获取预算

实际掉落表固定每次3–4枚咒魂锭（cursium_ingot）；唱片仅10%，不作为必需学习素材。若首批六项各消耗一锭＋魔源宝石，两次击杀保底覆盖；后续超过九项或加入消耗武器的配方时须重新核对总预算，必要时采用锭碎片。图标可以引用断魂战戟，不意味着配方必须消耗它。

最初规划时没有构建／部署／启动游戏。dev.44的实施与验证记录见[maledictus-first-dev44.md](maledictus-first-dev44.md)。客户端外观仍未人工验收。
