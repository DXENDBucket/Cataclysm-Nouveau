# 友军执行与共用转向（dev.39）

## 修正

用户指出：增益命中敌方应失败且不扣Mana，不能回退为施法者执行；友军执行体术未随友军视角转向，并要求自身/友军使用同一套逻辑。

所有身体行动现在共用`ActionGeometry`，由原`IgnisActionGeometry`推广。锚点身份、友军权限仍复用Conflux已有`ExecutionAnchor.beneficial`；没有新增Core代码或附属之间的依赖。

- 守卫上勾、闪现、空降、火箭拳与巨兽肩撞取消敌方命中→施法者执行的旧回退。已有焰魔/斯库拉/先驱者等入口统一使用同一个实际执行者授权。
- 焰魔火球阵、先驱者两种齐射及死亡激光的执行实体也只能是自身/友军，固定位置仍可用。持续增益继续遵守原目标限制；伤害区域等直接敌方效果保留。
- 23种执行/增益入口的敌方和非生物实体命中均验证不扣对应能力触发费用、不生成新行动、不替换已运行身体动作。已经发射弹射物的原生Ars形态起手费用不因此退款。
- 权限按真正施法者判断，不能借伤害归属或先前executor的友军关系取得敌人的身体。

## 同一条转向路径

`ActionGeometry`提供统一的实体选择、身份/权限检查、原点/包围盒、期望方向、水平限速转向、空间方向与攻击帧姿态。自身和友军仅传入不同的实际执行实体，没有两套转向实现。

玩家读取该执行玩家的视角；生物按该执行生物的有效攻击目标或视线。垂直看向天空/脚下时，水平朝向来自该执行者自己的yaw，不回退到付款者。固定点使用触发时冻结方向。

各动作保留自己的原生准备/攻击窗口：准备期转向，每tick最多20度；定向打击/突进窗口锁向。旋转挥锚和肩撞允许持续转向。先驱者在蓄势中转向，冲锋冲量释放后保持方向；钩锚在抛出前转向，抛出后不弯曲既有锚轨迹。焰魔原生窗口保留。攻击、移动冲量与幻影使用同一份朝向。

原生Goal可修改自己的朝向，调用后重新施加共享姿态，避免损伤朝向与模型不一致。先驱者首次同步前也重新采样实际执行者，修复构造器曾读取付款者方向的问题。后续失去友军资格的身体行动会按已有会话规则结束。
