# 剑舞的执行锚点与转向（dev.33）

本批仅迁移焰魔剑舞；不改变其他动作魔符的历史选点语义，也不修改固定 Core 0.1.19。使用原生 Combo1／Combo2 Goal、aiStep 和攻击体；没有复制灾变实现或资源。

## 锚点与角色

`ActionAnchor` 区分实际实体和世界坐标，独立于 `CastContext` 的施法者、资源账户与伤害来源。`beneficial` 只允许自身／友军实体，或真实方块命中位置；敌方实体、非生物实体和 MISS 失败，不隐式改为施法者执行，也不收费。

- 实体锚点：跟随实体位置和碰撞框，原生冲量仍应用于执行者；移动冲突检查与动作锁只作用于该实体。
- 位置锚点：使用触发的精确位置，不额外抬高或找地面。固定人形调用框（0.6×1.8），并不创建实体；原生打击范围与时序仍由原模组决定。两段伤害发生在此位置，原生冲量不移动幻影或施法者。此模式不占用根施法者的动作状态，也不在结束时衰减他的速度。
- 两者都保留根施法者伤害来源、回血对象、增强与费用。固定位置仍受根施法者死亡、移除、换维度和已加载范围限制，不加载额外区块。
- Native Goal 需要生物 target，使用未注册的 ArmorStand 作为输入适配器；它只表达瞄准点，不是执行者、友军、付款者或伤害对象，结束时清理。

增益是实体目标权限，不意味着禁止位置执行。这里抽出的锚点仅是附属内的实际执行姿态，不能把位置塞进 Core 的 LivingEntity executor，也不能更改付款／伤害归属。

## 朝向

实体玩家取当前视角，生物优先取有效攻击目标（32格内同世界敌方实体），没有目标则尝试当前视线中的敌人，最后采用自己的朝向。窗口内每 tick 最多转 20°；不改玩家镜头或生物自身朝向。

剑舞准备窗口：COMBO1 为 1–16、45–58；COMBO2 为 1–26、44–56、62–71、78–104。其他时刻锁定，包括挥击、冲撞及收尾地面冲击。原生 Goal 的自主转向在攻击前被统一姿态覆盖，服务端伤害与视觉快照共用该帧。玩家第二段的冲锋落点按锁定方向提供给原生 Goal，不用早先捕获敌人的预测覆盖镜头瞄准。

位置朝向在触发时冻结：优先采用弹射物入射方向的水平分量，否则采用根施法者水平朝向，完全竖直时使用 +Z。位置剑舞是水平动作，不是三维吐息。之后施法者转动镜头、移动，不改变落点朝向。

## 客户端与验证

幻影载荷增加显式位置锚点标志，协议版本升为 2。位置锚点不要求客户端存在某个实体，不复用施法者 entity id；向锚点附近96格观察者发送，并通知玩家施法者。实体模式沿用追踪实体发送。生命周期结束仍有明确关闭包和16tick租约兜底；切世界清空。

实体模式按执行者插值位置绘制；位置模式按载荷中的固定点绘制。两者都短暂插值服务端朝向，不让客户端独立瞄准或攻击。第一人称降透明度只应用于实际玩家实体锚点，不应用于他的远程幻影。

新服务端集成测试覆盖玩家转向／出手锁向与实际伤害方向、位置协议往返／两段自然结束／根取消／费用与友军／根运动保持、敌方实体拒绝退款以及友军生物根据攻击目标执行。客户端显示变化仍需人工验证。
